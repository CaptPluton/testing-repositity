# Агент-продажник OMG (v2)

Автономный агент: ищет клиентов под ICP (бьюти / обучение / медицина, МСБ РФ/СНГ), готовит холодные письма (≤10/день) с A/B-тестами, ведёт переписку, эскалирует сложное Яне и доводит лидов до созвона — с событием в Google Календаре и подготовкой в Asana. После выигрыша сделки передаёт клиента в работу агентства.

## Запуски (Asia/Omsk)

| Запуск | Расписание | Сценарий |
|---|---|---|
| Поиск + письма + фоллоу-апы | будни 09:07 (холодные — только вт–чт) | `prompts/prospecting.md` |
| Обработка ответов | будни 11:12 / 14:12 / 17:12 / 20:12 + сб 14:12 | `prompts/inbox.md` |
| Обзор стратегии | пт 18:10 | `prompts/weekly-review.md` |

Правила поведения — `playbook.md`; параметры — `config.yaml`. Страховка от смерти сессии: GitHub Actions watchdog (`.github/workflows/watchdog.yml`) откроет issue, если ветка молчит >26 ч в будни.

## Единая связка

- **CRM** — `state/leads.json` (единственный источник правды), коммитится в git после каждого запуска.
- **Asana, проект [«Продажи (агент OMG)»](https://app.asana.com/1/1211834135019768/project/1216283918610576)** — очередь действий Яны: «Отправить сегодня» (батчи писем), «Эскалации» (решения возвращаются агенту через комментарии/завершение задач), «Созвоны» (подготовка + исход), «Передача в работу» (создание клиентского проекта + онбординг в «Агентство»), «Настройка системы». Еженедельный status update с цифрами.
- **Gmail** — черновики и чтение ответов (отправляет всегда Яна); при недоступности — outbox-файлы в `outbox/` с чек-блоком подтверждения.
- **Google Календарь** — созвоны с Google Meet; статус `call_scheduled` только при созданном событии.
- **Google Диск** — [отчёт-таблица](https://docs.google.com/spreadsheets/d/1z29MQrQqSTujSEeA9MjtzId4oj52D3-HKNFjSnkWXRw/edit): журнал, воронка с разрезами, когорты по неделям, эксперименты. Перегенерируется из CRM (`report/build_report.py`), руками не правится.

## Цикл улучшения стратегии

Каждое письмо получает вариант A/B активного эксперимента (один фактор за раз, очередь: CTA → тема → длина → кейс/расчёт). Пятничный `weekly-review` считает когорты (`build_report.py --json`), решает по правилам «ворот выборки» из плейбука и меняет стратегию только после подтверждения Яны (Asana-задача «Согласовать: …»). История гипотез и решений — `state/weekly.json`.

## Управление

- Подтверждение отправки писем: завершить задачу в «Отправить сегодня» или написать в чат «письма отправлены».
- Пауза: попросить Claude отключить cron-задачи.
- Ручной канал при сломанном Gmail: пересланные ответы — в `inbox-manual/`.
