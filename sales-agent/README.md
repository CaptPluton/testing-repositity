# Агент-продажник

Автономный агент, который ищет клиентов для агентства, готовит холодные письма (≤ 10/день), ведёт переписку с ответившими, эскалирует сложные вопросы Яне и доводит лидов до созвона — с созданием события в Google Календаре.

## Как это работает

Два регулярных запуска (routines в Claude Code), которые «будят» сессию по расписанию:

| Запуск | Расписание (Омск, UTC+6) | Сценарий |
|---|---|---|
| Поиск + холодная рассылка | будни, 09:00 | `prompts/prospecting.md` |
| Обработка ответов | будни, 11:00 / 14:00 / 17:00 | `prompts/inbox.md` |

Каждый запуск: подтягивает эту ветку из git → читает `config.yaml` и `state/` → работает через Gmail и Google Calendar → коммитит обновлённое состояние обратно.

**Важно про отправку**: Gmail-коннектор умеет только создавать **черновики**. Агент готовит письма, а отправляете вы — одним кликом в Gmail. Это и предохранитель: ни одно письмо не уйдёт без вашего взгляда. О готовых черновиках агент сообщает push-уведомлением.

## Воронка

1. Агент ищет компании под ваш ICP (веб-поиск, только публичные контакты) и кладёт до 10 персонализированных холодных писем в черновики.
2. Вы отправляете черновики из Gmail.
3. Агент отслеживает ответы: отвечает на вопросы, рассказывает об услугах, делает до 2 фоллоу-апов.
4. Сложные вопросы (цены вне конфига, конфликты, «позовите руководителя») — эскалация: метка `Продажи/Нужна Яна` + push-уведомление вам.
5. Лид готов на созвон → агент согласовывает время по вашему календарю, создаёт событие (Google Meet, участник — лид, описание договорённостей) и уведомляет вас.

## Настройка (обязательно перед первым запуском)

Заполните в `config.yaml` разделы `agency` (название, сайт, услуги, кейсы, что говорить о ценах) и `icp` (кто ваш клиент, отрасли, география). **Пока они пустые, агент не рассылает письма** — только напоминает заполнить конфиг.

Также можно поменять: лимит писем в день, рабочие часы для созвонов, длительность звонка, тон.

## Управление

- **Пауза/остановка**: попросите Claude в этой сессии отключить routines (`update_trigger enabled=false`) или удалить их.
- **Файлы состояния**: `state/leads.json` — CRM со всеми лидами и историей, `state/activity-log.json` — дневные счётчики квоты. Редактируются агентом, но можно править руками (например, вручную добавить лида).
- **Правила поведения агента**: `playbook.md`. Шаблоны писем: `templates/`.
