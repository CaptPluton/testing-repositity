# Шаблон касания «новооткрытый бизнес» (сегмент newbiz)

Особый сегмент: бизнесы, открывшиеся за последние 1–6 месяцев. Цель — написать первыми, пока они не выбрали подрядчика.

## Ключевые особенности сегмента

- **Email почти никогда нет в открытом доступе** → основной канал первого касания: **сообщение в сообщество ВК** или звонок администратору с просьбой передать/дать почту владельца. Письма по email — только если адрес найден дословно.
- Не входит в лимит холодных писем (10/день), если касание идёт через ВК/телефон; email-касания newbiz — в общий лимит.
- Повод всегда конкретный: факт открытия (новость, премия «Открытие года», карточка «Новое» в 2ГИС). Указывать источник — это персонализация.
- Боль сегмента: план выручки с первого месяца при нулевом сарафане. Оффер — быстрый поток заявок из таргета ВК/Директа + (для стоматологий/клиник) заявки с фиксированной ценой в договоре.
- Правила плейбука действуют полностью: не утверждать отсутствие, конфиденциальность источников лидгена, без спам-слов.

## Структура сообщения ВК (60–100 слов)

1. Поздравление с открытием + откуда узнали (новость/премия/2ГИС) — 1 предложение.
2. Кто мы — 1 предложение (нишевая подпись из cold-email.md).
3. Боль новичка: первые месяцы поток записей приходится собирать вручную — реклама ускоряет. 1 предложение.
4. Кейс своей ниши (1 цифра, из config.cases).
5. CTA: «посчитаю бесплатно, сколько будет стоить заявка/запись в вашем районе — по открытым данным рекламного аукциона. Интересно?»

## Источники новых бизнесов (проверено 07.07, детали в notes лидов)

Еженедельная связка (пн, вместе с prospecting):
1. **Rusprofile/Checko расширенный поиск** — ОКВЭД 96.02 / 86.21–86.23 / 85.41 + регион + «дата регистрации: последние 30 дней». Даёт ФИО директора (ЛПР) сразу. Выгрузки платные — предложить Яне тариф, без него смотреть вручную.
2. **2ГИС фильтр «Новое»** (метка живёт 3 мес) + **Zoon-страницы «Новые салоны красоты в {городе}»** — телефон/сайт/соцсети для верификации. Бесплатно.
3. **Городские порталы сети Shkulyov** (НГС, E1, 72.ru, NN.RU, 63.ru…) — теги «салон красоты»/«клиника» + ежегодные списки «Открытие года» (апрель–май; включая премию 2ГИС «Открытие года» — бизнесы младше 6 мес). Три касания батча №1 newbiz найдены именно так.
Верификация перед касанием: факт открытия (СМИ/премия) + живая карточка 2ГИС/ВК; юрлицо в Rusprofile — если нужен ЛПР.
