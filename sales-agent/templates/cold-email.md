# Шаблон холодного письма (v2)

Обычный текст без HTML. Вариант A или B определяется активным экспериментом (`weekly.json`); поля `variant`/`experiment_id` пишутся в лида. Пока эксперимент не запущен — вариант B (созвон) как дефолт.

## Правила темы

3–6 слов, про их бизнес, без слов «реклама», «трафик», «продвижение», «бесплатно», «скидка» (спам-триггеры и баннерная слепота). Дефолтный архетип — «наблюдение» («Идея по записям для {студия}»). Архетип «вопрос с именем» («{Имя}, вопрос по записям в {студия}») используется ТОЛЬКО когда фактор активного эксперимента — тема; при любом другом факторе (в т.ч. EXP-001-cta) тема у вариантов A и B одинаковая — иначе эксперимент неинтерпретируем (один фактор за раз).

## Структура (≤120 слов, если A/B не тестирует длину)

1. **Гейткипер-блок** — только для generic-ящиков (info@, salon@): первая строка «Подскажите, как передать короткое предложение {владельцу/директору — по имени, если известно}? Продублирую на нужную почту.» Пропустить, если адрес личный ИЛИ письмо обращается к ЛПР по имени и ящик явно её/его (авторская студия, личный бренд).
2. **Зацепка (1–2 предложения)** — конкретное наблюдение про них (сайт, отзывы, запись, соцсети). Должно быть видно, что письмо писали им.
3. **Мостик к боли (1 предложение)** — из нишевого блока ниже.
4. **Ценность (1–2 предложения)** — оффер (платный трафик/SMM) + кейс из `config.cases` своей ниши. Кейсы с `no_metrics: true` — только как «работаем с {клиент}, знаем нишу изнутри», без цифр. Альтернатива кейсу — честный расчёт: «посчитаю ориентировочную стоимость заявки по вашему району по открытым данным рекламного аукциона ВК».
5. **CTA (1 предложение)** — по варианту:
   - **A (микро-ценность)**: «Могу прислать мини-разбор в 10 строк — 3 конкретных идеи по записям для вас. Ответьте "да" — пришлю, без обязательств.»
   - **B (созвон)**: «Будет ли удобно созвониться на 20 минут на этой неделе? Первая консультация бесплатная — расскажу, что улучшить конкретно у вас.»
6. **Подпись** — {sender_name}, {агентство} + нишевая формулировка (не «полного цикла»): бьюти — «приводим записи салонам и студиям»; обучение — «снижаем стоимость заявки школам и курсам»; медицина — «платный трафик и SMM для клиник». Одна ссылка: сайт с UTM (`outreach.utm`). Instagram/TG в первом касании не давать (TG-канал — со 2-го касания).
7. **Opt-out** — строка из конфига.

## Нишевые блоки (боль / сезонность)

- **Бьюти**: пустые окна в расписании и записи «только по телефону»; таргет ВК на онлайн-запись; сезонность — сертификаты и парные программы к праздникам (НГ, 8 марта), «подготовка к лету».
- **Обучение**: дорогая заявка и зависимость от сарафана; Директ по горячим запросам + квизы; сезонность — осенний/весенний набор («к сентябрю группы должны быть собраны в августе»). **Второй оффер (обязателен)**: заявки с фиксированной ценой из `config → lead_gen_fixed_cpl` — цена в договоре, номера с СМС-валидацией до CRM, канал масштабирования набора.
- **Медицина**: комиссии агрегаторов (ПроДокторов, 2ГИС) и чужая база; Директ по направлениям-локомотивам; упомянуть опыт с ограничениями мед-рекламы (ФЗ-38, маркировка) — это снимает главный страх клиник. **Второй оффер (обязателен)**: заявки на приём с фиксированной ценой (`lead_gen_fixed_cpl`) — цена в договоре, СМС-валидация номеров, выше дозвон. Конкретные цены CPA — только через Яну.

## Чего не делать

- Не начинать с «Меня зовут… я представляю…».
- Не перечислять услуги списком; один оффер из `priority_services`.
- Не обещать результат («удвоим продажи») и не выдумывать цифры кейсов.
- Не прикладывать вложения, не ставить два CTA.
- Не приводить Instagram-кейсы первым касанием для РФ-аудитории.
