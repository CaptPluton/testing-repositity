# Шаблон холодного письма (v2)

Обычный текст без HTML. Вариант A или B определяется активным экспериментом (`weekly.json`); поля `variant`/`experiment_id` пишутся в лида. Пока эксперимент не запущен — вариант B (созвон) как дефолт.

## Правила темы

3–6 слов, про их бизнес, без слов «реклама», «трафик», «продвижение», «бесплатно», «скидка» (спам-триггеры и баннерная слепота). Дефолтный архетип — «наблюдение» («Идея по записям для {студия}»). Архетип «вопрос с именем» («{Имя}, вопрос по записям в {студия}») используется ТОЛЬКО когда фактор активного эксперимента — тема; при любом другом факторе (в т.ч. EXP-001-cta) тема у вариантов A и B одинаковая — иначе эксперимент неинтерпретируем (один фактор за раз).

## Структура (≤120 слов, если A/B не тестирует длину)

1. **Гейткипер-блок** — только для generic-ящиков (info@, salon@): первая строка «Подскажите, как передать короткое предложение {владельцу/директору — по имени, если известно}? Продублирую на нужную почту.» Пропустить, если адрес личный ИЛИ письмо обращается к ЛПР по имени и ящик явно её/его (авторская студия, личный бренд).
2. **Зацепка (1–2 предложения)** — конкретное наблюдение про них (сайт, отзывы, запись, соцсети). Должно быть видно, что письмо писали им.
3. **Мостик к боли (1 предложение)** — из нишевого блока ниже.
4. **Ценность (1–2 предложения)** — оффер (платный трафик/SMM) + кейс из `config.cases` своей ниши. Кейсы с `no_metrics: true` — только как «работаем с {клиент}, знаем нишу изнутри», без цифр. Альтернатива кейсу — честный расчёт: «посчитаю ориентировочную стоимость заявки по вашему району по открытым данным рекламного аукциона ВК».
5. **CTA (1 предложение)** — по варианту:
   - **A (микро-ценность)**: «Могу прислать мини-разбор в 10 строк — 3 конкретных идеи по записям для вас. Ответьте "да" — пришлю, без обязательств.»
   - **B (созвон)**: «Будет ли удобно созвониться на 20 минут на этой неделе? Первая консультация бесплатная — расскажу, что улучшить конкретно у вас.»
6. **Подпись** — {sender_name}, {агентство} + нишевая формулировка (не «полного цикла»): бьюти — «приводим записи салонам и студиям»; обучение — «снижаем стоимость заявки школам и курсам»; медицина — «платный трафик и SMM для клиник». Ссылка на сайт с UTM (`outreach.utm`) + **строка соцсетей (указание Яны, 07.07)**: `Telegram: t.me/obgolts_media_group · Instagram: @obgolts_media` — действует с батча №4; ВК-сообщества агентства в базе нет (добавить, когда Яна пришлёт ссылку). Прежнее правило «TG-канал со 2-го касания» отменено.
7. **Opt-out** — строка из конфига.

## Нишевые блоки (боль / сезонность)

- **Бьюти**: пустые окна в расписании и записи «только по телефону»; таргет ВК на онлайн-запись; сезонность — сертификаты и парные программы к праздникам (НГ, 8 марта), «подготовка к лету». **Кейсы с цифрами** (`config → cases.beauty`) — один релевантный на письмо: эпиляция/косметология — «Гладкое тело» (сеть в 19 городах, 216 000 заявок по ~650 ₽) для сетей, «Евергло» (2 358 лидов по 550 ₽, запись 15% → 47%) или «Леди Лазер» (запись 60%) для студий; массаж — «XSize» (44 465 лидов по 592 ₽ за 21 мес); салоны — «Осипов имидж» (клиент открыл 3 новых салона). Цифры выручки Venesa не приводить (caution в конфиге).
- **Обучение**: дорогая заявка и зависимость от сарафана; Директ по горячим запросам + квизы; сезонность — осенний/весенний набор («к сентябрю группы должны быть собраны в августе»). **Кейс с цифрами (собственный кейс OMG)**: Академия Кинезиологии — заявки на обучение ×2,5 (7 → 25/мес) + 220 предзаписей на День открытых дверей, YouTube ×8,5, за 2 месяца без рекламного бюджета — идеален для школ с экспертным контентом. **Второй оффер (обязателен)**: заявки с фиксированной ценой из `config → lead_gen_fixed_cpl` — цена в договоре, номера с СМС-валидацией до CRM, канал масштабирования набора.
- **Медицина**: комиссии агрегаторов (ПроДокторов, 2ГИС) и чужая база; Директ по направлениям-локомотивам; упомянуть опыт с ограничениями мед-рекламы (ФЗ-38, маркировка) — это снимает главный страх клиник. **Кейсы с цифрами** (`config → cases.medicine`, partner: true — формулировать «мы с партнёрской командой Prof Digital»): один релевантный кейс на письмо — для стоматологий «Команда Мечты»/Dentis (заявки 1 100–1 800 ₽), для клиник/медцентров «Волгамед» (приход −23%) или «Хелз Лайф» (приход 8 998 → 5 264 ₽). **Второй оффер (обязателен)**: заявки на приём с фиксированной ценой (`lead_gen_fixed_cpl`) — цена в договоре, СМС-валидация номеров, выше дозвон; для стоматологий подкреплять цифрами нашего агрегатора заявок (20 000+ лидов в 20+ городах, 58–71% квалифицированных, доходимость из записи до 75%) — **название сервиса НЕ раскрывать** (правило конфиденциальности в плейбуке). Конкретные ставки, цены CPA и пакеты — только через Яну.

## Чего не делать

- Не начинать с «Меня зовут… я представляю…».
- Не перечислять услуги списком; один оффер из `priority_services`.
- Не обещать результат («удвоим продажи») и не выдумывать цифры кейсов.
- Не прикладывать вложения, не ставить два CTA. **Исключение (указание Яны, 07.07): стоматологиям прикладываем презентацию кейсов** `assets/OMG-кейсы-стоматологии.pptx` (5 клиник с воронкой до выручки) — в тексте письма одна строка об этом после кейс-абзаца. Технически: агент упоминает презентацию в тексте и указывает в Asana-задаче/чате, что файл прикрепляет Яна вручную перед отправкой (передача файла через API ненадёжна — крупный base64 повреждается). То же в фоллоу-апах стоматологиям, если в холодном письме вложения не было.
- Не приводить Instagram-кейсы первым касанием для РФ-аудитории.
- Не упоминать Facebook и не строить на нём аргументацию — в РФ им почти не пользуются, это нерелевантный сигнал. Основные соцсети для разведки и аргументов: ВК, Instagram, Telegram.
- **Не утверждать отсутствие**: никаких «у вас нет ВК», «ВКонтакте не находится», «Telegram пустует» — ссылки на соцсети часто стоят прямо на сайте лида и не попадают в поисковые сниппеты. Зацепка — только на позитивно подтверждённых фактах; боль формулировать мягко («если записи в основном с карт и по сарафану…») или вопросом. Найденное живое сообщество — наоборот, повод для комплимента и аргумент «аудитория уже собрана — осталось направить на неё рекламу».
