# Шаблон холодного письма

Структура (итог ≤ 120 слов, без HTML-украшательств, обычный текст):

**Тема**: конкретная и спокойная, про их бизнес, без кликбейта.
Примеры: «Идея по записям для {название студии}», «Вопрос по сайту {компания}».

**Тело**:

1. **Зацепка (1–2 предложения)** — персонализация: что именно ты увидел у них (сайт, отзывы, ниша, город). Должно быть понятно, что письмо писали им, а не «в базу».
2. **Мостик к боли (1 предложение)** — какая типовая задача/проблема у таких компаний, которую агентство решает.
3. **Ценность (1–2 предложения)** — чем агентство может помочь + один релевантный кейс с цифрой из `config.yaml → agency.cases`, если есть.
4. **CTA (1 предложение)** — короткий созвон 20–30 минут с Яной: «Будет ли вам удобно созвониться на 20 минут на этой неделе?»
5. **Подпись** — имя (`sender_name`), агентство, сайт.
6. **Opt-out** — строка из `config.yaml → outreach.opt_out_line`.

## Пример (заполняется реальными данными из конфига)

> Тема: Идея по онлайн-записи для «Люмьер»
>
> Здравствуйте, Мария!
>
> Наткнулась на вашу студию, когда смотрела салоны Казани — отличные отзывы, но заметила, что записаться можно только по телефону, и в Instagram нет ссылки на онлайн-запись.
>
> Мы в {агентство} как раз помогаем салонам получать больше записей: {услуга 1} и {услуга 2}. Например, {кейс с цифрой}.
>
> Будет ли вам удобно созвониться на 20 минут на этой неделе? Расскажу, что можно улучшить конкретно у вас, — без обязательств.
>
> {sender_name}, {агентство}
> {сайт}
>
> {opt_out_line}

## Чего не делать

- Не начинать с «Меня зовут… я представляю компанию…» — сразу к делу.
- Не перечислять все услуги списком — только 1–2 релевантные.
- Не обещать конкретных результатов («удвоим продажи») — только реальные кейсы из конфига.
- Не ставить больше одного CTA и не прикладывать вложения.
