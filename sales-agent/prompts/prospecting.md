# Сценарий: ежедневный поиск клиентов и холодная рассылка

Выполняется раз в день по будням. Перед началом прочитай `sales-agent/playbook.md` и `sales-agent/config.yaml` — все правила и параметры оттуда.

## Шаги

### 0. Подготовка
1. `git fetch origin claude/sales-agent-email-odes7k && git checkout claude/sales-agent-email-odes7k && git pull origin claude/sales-agent-email-odes7k`.
2. Прочитай `config.yaml`, `state/leads.json`, `state/activity-log.json`.
3. **Guard**: если `agency.name` или `icp.description` пустые — отправь Яне push-уведомление «Заполни sales-agent/config.yaml, без этого не могу начать рассылку» и заверши запуск.
4. Убедись, что Gmail-метки из `gmail_labels` существуют (`list_labels`), недостающие создай.

### 1. Сверка отправленного (реконсиляция)
Для каждого лида со статусом `drafted`: поищи `in:sent to:<email>` в Gmail. Нашлось — статус `sent`, запиши `thread_id` и дату отправки. Для лидов `sent` без ответа, у которых прошло ≥ `followup_after_days` и фоллоу-апов меньше `followups_max`, — создай черновик фоллоу-апа (reply в ту же цепочку, шаблон в `templates/followup.md`), увеличь счётчик фоллоу-апов лида.

### 2. Проверка квоты
- Из `activity-log.json` возьми число холодных черновиков за сегодня; доступно = `daily_cold_email_limit − уже создано`. Если 0 — переходи к шагу 5.
- Посчитай неотправленные холодные черновики (лиды в статусе `drafted`). Если их ≥ `max_pending_drafts` — новых не создавай, уведомь Яну, что черновики копятся неотправленными, и переходи к шагу 5.

### 3. Поиск новых лидов
1. Через `WebSearch`/`WebFetch` ищи компании под ICP: по отраслям и географии из конфига (каталоги, карты, отраслевые рейтинги, свежие новости об открытии бизнеса и т.п.).
2. Для каждого кандидата зайди на сайт: пойми, чем занимаются, найди **публичный** email (контакты, футер) и, если возможно, имя владельца/ЛПР.
3. Отсеивай: дубликаты по email и домену против всего `leads.json` (включая `unsubscribed` и `not_interested`), несоответствие ICP, `disqualifiers`, адреса вида noreply.
4. Набери лидов чуть больше квоты (на случай брака), но черновиков создай не больше доступной квоты.

### 4. Черновики холодных писем
Для каждого нового лида (в пределах квоты):
1. Напиши письмо по `templates/cold-email.md`: персонализация про их бизнес, оффер из `outreach.priority_services` (остальные услуги — только если очевидно релевантны лиду), подходящий кейс (если есть), CTA — короткий созвон, строка opt-out.
2. `create_draft` (to = email лида, тема — конкретная и спокойная).
3. Добавь лида в `leads.json`: статус `drafted`, компания, сайт, имя, email, источник, дата, заметка о персонализации, `history`.
4. Увеличь счётчик в `activity-log.json` за сегодня.

### 5. Завершение
1. Обнови `state/*.json`, закоммить и запушь (правила git — в плейбуке).
2. Пересобери отчёт: `python3 sales-agent/report/build_report.py` (при отсутствии openpyxl — `pip install openpyxl`). Правила обновления Google Таблицы — в плейбуке, раздел «Отчётность».
2. Push-уведомление Яне: сколько черновиков готово («Проверь и отправь черновики в Gmail: N холодных + M фоллоу-апов»), сколько лидов найдено, есть ли проблемы.
3. В финальном сообщении — краткий отчёт: найдено / создано черновиков / фоллоу-апы / пропущено и почему.
