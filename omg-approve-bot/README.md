# OMG approve bot · бот согласования и публикации

Новый бот для @omg_approve_bot, написан с нуля. Старый код, старая таблица, личный контур и кружки не используются. Бот знает одну таблицу «OMG · Маркетинг · Показатели», лист «Согласование», и два канала публикации: Telegram и YouTube. Instagram и Threads через бота не идут.

## Что делает

1. Каждые 2 минуты читает лист «Согласование». Для строк с каналом Telegram или YouTube и статусом «на согласовании» присылает Яне карточку: канал, формат, рубрика, время, риск, текст, CTA, число медиафайлов.
2. Кнопки карточки: «Ок, по расписанию», «Опубликовать сейчас» (для YouTube «Прислать пакет сейчас»), «Правки», «Отменить».
3. «Ок»: статус в таблице «ок», пост ждёт времени из колонок «Дата публикации» и «Время (Пхукет)» и выходит сам. Если Яна ставит «ок» прямо в таблице, это тоже одобрение.
4. Telegram: бот публикует текст и медиа в канал, записывает в таблицу статус «опубликовано» и ссылку на пост. Жирный в тексте: `**так**`, курсив: `__так__`.
5. YouTube: за 30 минут до времени бот присылает пакет (заголовок, описание, теги из колонки «Текст», ссылки на файлы). Яна загружает в YouTube Studio, нажимает «Опубликовано» и присылает ссылку: бот записывает её в таблицу.
6. Медиа: по умолчанию ссылки на Google Диск из колонки «ТЗ на визуал / файл» (бот скачивает сервисным аккаунтом, до 10 файлов, до 50 МБ каждый). Если ответить на карточку фото или видео, они заменят ссылки.
7. «Правки»: бот спрашивает текст правок, пишет его в «Комментарий Яны», статус «правки». Когда агент вернёт строку «на согласовании», придёт новая карточка.
8. Если текст или время изменились, пока карточка висит, бот присылает новую версию.
9. Утром в 09:00 по Пхукету дайджест ожидающих карточек. Команды: /pending, /today, /check, /help.
10. Отвечает только одному Telegram-аккаунту (OWNER_TG_ID). Остальных игнорирует.

## Колонки листа «Согласование»

Бот ищет колонки по заголовкам, порядок не важен: «Дата публикации», «Время (Пхукет)», «Канал», «Формат», «Рубрика», «Первая строка», «Текст», «ТЗ на визуал / файл», «CTA», «Статус», «Комментарий Яны», «Риск», «Ссылка на публикацию», «Код». Статусы: черновик, на согласовании, ок, правки, опубликовано, отменено. Канал: любое значение со словом Telegram или YouTube.

## Установка за 30 минут

1. **Сервисный аккаунт Google.** В console.cloud.google.com создайте проект (или возьмите тот, что делали для старого бота), включите Google Sheets API и Google Drive API, создайте сервисный аккаунт и JSON-ключ. Дайте email сервисного аккаунта доступ «Редактор» к таблице и «Читатель» к папке OMG на Диске (чтобы качать медиа).
2. **Бот.** В @BotFather можно оставить тот же бот и токен. Добавьте бота администратором канала с правом публикации. Узнайте свой Telegram ID через @userinfobot.
3. **Railway.** Новый проект из этого репозитория, корень `omg-approve-bot`. Переменные окружения из `.env.example`: BOT_TOKEN, OWNER_TG_ID, TG_CHANNEL_ID, SHEET_ID, GOOGLE_SERVICE_ACCOUNT_JSON (содержимое JSON-ключа одной строкой), TZ. Подключите Volume в `/data`, чтобы база переживала деплои. Старый сервис бота остановите, иначе два бота будут отвечать с одного токена.
4. **Проверка.** Напишите боту /check: он назовёт таблицу и число строк. Положите тестовую строку с каналом Telegram и статусом «на согласовании», через 2 минуты придёт карточка.

## Локальный запуск

```
cd omg-approve-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить
python -m bot
```

Тесты логики без сети: `pip install pytest && pytest`.

## Структура

- `bot/rows.py` чтение строк листа, статусы, время, ссылки на Диск (чистая логика, есть тесты)
- `bot/sheet.py` Google Sheets, `bot/drive.py` скачивание медиа
- `bot/service.py` одобрение, публикация, пакеты YouTube, планировщик
- `bot/handlers.py` команды и кнопки, `bot/publisher.py` отправка в канал
- `bot/db.py` SQLite-состояние (новая база = чистая память бота)
