# OMG: отдел маркетинга и бот согласования. С чего начать

В архиве две папки.

## 1. omg-marketing-department (отдел маркетинга в Claude Code)
1. Распакуйте папку куда удобно, например ~/OMG/omg-marketing-department.
2. Откройте её в Claude Code: приложение Claude для Mac, раздел Code, «Открыть папку». Или в Терминале: cd ~/OMG/omg-marketing-department && claude
3. На вопрос «доверять ли папке» ответьте «да».
4. Подключите один раз: расширение Claude in Chrome (войдите в Chrome в Instagram, Threads, YouTube Studio, Telegram Web, ChatGPT, HeyGen, Kling, Google Sheets), коннектор Google Drive в настройках Claude, приложение iPhone Mirroring.
5. Первая команда в сессии: /bootstrap. Потом /account-audit, /design-concept, /morning.
Подробно: omg-marketing-department/README.md

## 2. omg-approve-bot (бот согласования @omg_approve_bot)
1. Сервисный аккаунт Google: console.cloud.google.com, включить Google Sheets API и Google Drive API, создать сервисный аккаунт и JSON-ключ. Дать его email доступ «Редактор» к таблице «OMG · Маркетинг · Показатели» и «Читатель» к папке OMG на Диске.
2. Railway: новый сервис из папки omg-approve-bot (загрузить через GitHub или railway up из папки). Переменные из omg-approve-bot/.env.example. Volume в /data. Старый сервис бота остановить.
3. Написать боту /check.
Подробно: omg-approve-bot/README.md
