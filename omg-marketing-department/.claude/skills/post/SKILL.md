Подготовь публикацию: канал $0, тема: $ARGUMENTS.

Перед работой прочитай knowledge/brand.md, раздел канала в knowledge/channels.md, нужный сегмент в knowledge/audience.md, state/winners.md. Для офферов: knowledge/services.md, knowledge/niches.md.

Делай по процессу smm-lead (диагностика 7 строк, 8 хуков, текст, критики, рубрика, факты). Выдай:

1. Диагностика: 7 строк.
2. Хуки: 3 отобранных с баллами, 1 строкой почему отбросил остальные.
3. Текст поста под лимиты канала (знаки в скобках). Для карусели: текст по слайдам. Для рилса: сценарий по кадрам с таймингом и текстом на экране, режим видео (Яна / аватар / без лиц) с обоснованием. Для YouTube: хук 0:00-0:15, структура, b-roll, заголовок до 60 знаков, описание, теги.
4. ТЗ на визуал для designer: формат, заголовок обложки до 7 слов, что пруф.
5. CTA: один, соразмерный рубрике. Для Meta-сетей с оффером: метка [РИСК 10.7].
6. Паспорт: рубрика, стадия воронки (TOFU/MOFU/BOFU), сегмент, механизмы, гипотеза «если, то, потому что», баллы рубрики, вердикт юриста, основание каждой цифры.
7. Строка для листа «Согласование» по templates/post-brief.md, статус «на согласовании», время публикации по Пхукету и Москве. Для Telegram и YouTube строка должна быть в формате, который читает бот @omg_approve_bot: колонка «Канал» содержит слово Telegram или YouTube; «Дата публикации» в формате ДД.ММ.ГГГГ; «Время (Пхукет)» в формате ЧЧ:ММ; «Текст» готов к публикации как есть (жирный **так**, курсив __так__, без markdown-заголовков); медиа загружены в папку OMG на Google Диске и ссылки на файлы записаны в «ТЗ на визуал / файл» (до 10 файлов, до 50 МБ каждый, картинки и видео, не Google-документы); для YouTube в «Текст» идут заголовок, описание, теги и таймкоды, а ссылка на видеофайл в колонке медиа; «Статус» строго «на согласовании». Для Instagram и Threads дополнительно собери пакет для ручной публикации Яной в outputs/ГГГГ-ММ-ДД/<код>/: caption.txt, первый комментарий с хэштегами, файлы визуала или видео, слайды по порядку, время, напоминание о метке «ИИ-контент», если применимо.

В чат: ссылка на строку (или путь к файлу черновика в outputs/, если таблица недоступна) и первая строка текста. Текст целиком в чат не вставляй, если Яна не попросила.
