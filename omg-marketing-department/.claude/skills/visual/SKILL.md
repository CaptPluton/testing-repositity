Визуал: $ARGUMENTS. Делает designer.

1. ТЗ по knowledge/brand.md раздел «Визуал»: формат под канал (4:5, 9:16, 16:9), композиция, текст на слайдах, пруф.
2. Промт для ChatGPT (генерация изображения), шаблон: «Создай изображение [формат, соотношение сторон]. Стиль: тёмный фон #0A0A0A с лёгким зерном, один акцент красно-оранжевый градиент, минимализм, редакционная подача, без текста, без логотипов, без реальных лиц. Сюжет: [сцена или метафора из поста, конкретная, без офисных стоков]. Композиция: [где оставить место под заголовок]. Настроение: [дерзко, честно, по делу].» Текст на картинку не генерируем: накладываем сами (ошибки в буквах у генераторов).
3. Через Chrome: открыть ChatGPT, отправить промт, скачать результат в outputs/ГГГГ-ММ-ДД/, при необходимости 2 итерации (не больше).
4. Наложение заголовка: описать в ТЗ (шрифт Manrope, верхний регистр, цвет, позиция) для финальной сборки в Figma или Canva; если есть локальный инструмент (ImageMagick, Pillow), собрать черновик автоматически.
5. Чек-лист: читается на превью 3×3; один акцентный цвет; нет чужих брендов и лиц; заголовок совпадает с хуком; нет «до/после» в здоровье; размер верный. Ссылку на файл вписать в строку согласования.
