# OMG Marketing Department · отдел маркетинга Obgolts Media Group на Claude Code

Папка проекта для Claude Code на Mac. Внутри живёт отдел маркетинга из семи ролей, который ведёт соцсети агентства, следит за деньгами (цель: ДРР не выше 10%), ежедневно сверяется с законами о рекламе в РФ, новостями нейросетей и вирусными поводами, ведёт отчётную таблицу и сам корректирует стратегию.

Голос везде: «мы» агентства OMG. Личный бренд Яны этот проект не ведёт.

## Что внутри

| Путь | Что это |
| --- | --- |
| `CLAUDE.md` | Конституция отдела. Загружается всегда. Цель, иерархия правил, кто есть кто, как принимаются решения. |
| `.claude/agents/` | Семь ролей: старший маркетолог (куратор), SMM-лид, аккаунт-менеджер, аналитик, продажник, дизайнер, исследователь. |
| `.claude/skills/` | Команды: `/morning`, `/post`, `/content-plan`, `/weekly-report`, `/competitor-audit`, `/account-audit`, `/bootstrap`, `/funnel`, `/comments`, `/visual`, `/video`, `/newsjack`, `/community`, `/finance-check`. |
| `knowledge/` | База знаний: бренд, аудитория и её боли, услуги и прайс, ниши, конкуренты, каналы, право РФ, научная база, источники, инструменты, комьюнити, индекс Диска. |
| `templates/` | Шаблоны: отчётная таблица, бриф поста, утренний бриф, недельный отчёт. |
| `state/` | Память отдела: журнал, победители, эксперименты, решения, кэш метрик. Агенты пишут сюда сами. |
| `.claude/settings.json` | Хук старта сессии: показывает дату, когда последний раз делали утренний бриф и статус ДРР. |

## Установка за 20 минут

1. **Claude Code на Mac.** Установите Claude Desktop или Claude Code CLI. Откройте эту папку как проект: `cd omg-marketing-department && claude`.
2. **Chrome.** Установите расширение Claude in Chrome и войдите в Chrome в свои аккаунты: Instagram, Threads, YouTube Studio, Telegram Web, ChatGPT, HeyGen, Kling, Google Sheets. Агент работает в ваших вкладках под вашими подписками, ключи API не нужны.
3. **Google Drive.** В настройках Claude подключите коннектор Google Drive тем же аккаунтом, где лежит папка OMG. Агент читает Диск сам.
4. **Зеркало iPhone.** macOS 15 и новее: откройте приложение iPhone Mirroring, подтвердите на телефоне. Для старых версий macOS: подключите iPhone кабелем, откройте QuickTime Player, Файл, Новая видеозапись, в выпадающем списке у кнопки записи выберите iPhone. Через зеркало агент смотрит статистику Instagram и Threads там, где веб-версия её не показывает.
5. **Отчётная таблица.** Уже создана в папке OMG на Диске: «OMG · Маркетинг · Показатели» (https://docs.google.com/spreadsheets/d/1wy6GP-TmYlIdugtytJlrcO2NCZJecvIxYkTKXC9qqs0/edit). Пока в ней один лист «Согласование»; остальные листы по `templates/report-sheet.md` добавит агент на `/bootstrap`.
6. **Первый запуск.** В сессии напишите `/bootstrap`. Агент соберёт всё про OMG с Диска и с этого Mac, обновит `knowledge/`, покажет пробелы и задаст вопросы. Потом `/morning`.

## Как работать каждый день

- Утро: `/morning`. Бриф за 5 минут: что изменилось в законах, в нейросетях, что завирусилось и как это адаптировать под OMG, что сегодня публикуем, где мы по ДРР.
- Посты: `/post <канал> <тема>` или просто «подготовь посты на неделю». Все посты уходят в таблицу согласования до 09:00, публикация после вашего «ок».
- Понедельник: `/weekly-report`. Агент заполняет таблицу показателей, считает ДРР двумя способами, предлагает правки стратегии.
- Раз в две недели: `/competitor-audit`, `/account-audit`.

## Ежедневный запуск без вашего участия

Вариант А (рекомендуем): в Claude Code на вебе (claude.ai/code) создайте Routine с расписанием на 08:00 по вашему времени и промтом `/morning`. Утренний бриф будет ждать вас в сессии.

Вариант Б: на Mac добавьте в Автоматор или launchd задачу, которая в 08:00 открывает Terminal и запускает `claude -p "/morning" --agent senior-marketer` в этой папке.

## Как это связано с тем, что уже есть

У агентства уже есть Claude-агенты (marketing-director, smm-strategist, наборы под ProfDigital и под инструменты, прогон в 10:00) и боты на Railway (@Obgolts_Media_bot, @omg_approve_bot, @prodmen88bot). Этот проект их не трогает: имена агентов здесь другие, конфликтов нет; агенты из `~/.claude/agents` остаются доступны во всех папках, агенты из `.claude/agents` этой папки имеют приоритет только внутри неё. Если захотите, чтобы публиковал бот согласования, а не агент, подключите лист «Согласование» к @omg_approve_bot и скажите об этом агенту: он перестанет публиковать сам.

## Границы и безопасность

- Агент никогда не публикует без статуса «ок» в таблице согласования. Исключений нет, даже для Threads.
- Агент не читает и не копирует файлы с доступами и паролями. Они нужны вам, не ему.
- Деньги клиентов, рекламные кабинеты клиентов и переписка с клиентами вне зоны проекта: он ведёт маркетинг самого агентства.
- Любая цифра в контенте имеет источник. Нет источника: ставится метка [УТОЧНИТЬ] и цифра не публикуется.
