# US IP Merch Advisor

Агент-консультант по американскому праву интеллектуальной собственности для продавцов мерча: товарные знаки, авторское право, право на образ, правила маркетплейсов, регистрация своего бренда и ведение бизнеса по штатам. Отвечает по-русски, термины и цитаты — на английском. Формат ответа: светофор (🟢/🟡/🔴/⚫) с легальными альтернативами; по слову «подробно» — полный меморандум с цитатами законов и дел.

## Как использовать в Claude (claude.ai)

1. Создайте Project → Instructions → вставьте содержимое `SYSTEM_PROMPT.md` целиком.
2. В Project knowledge загрузите все файлы из `reference/`.
3. Включите веб-поиск в проекте: агент обучен проверять USPTO, политики издателей и лицензионные программы перед вердиктом.
4. Задавайте вопросы как есть: «Хочу футболки с логотипом Fortnite на Etsy, можно?». Для развёрнутого анализа добавьте «подробно».

Если промт вставляется в обычный чат без Project — достаточно одного `SYSTEM_PROMPT.md`.

## Как использовать в Claude Code

Субагент `us-ip-advisor` подхватывается автоматически из `.claude/agents/`. Вызов:

```
Спроси субагента us-ip-advisor: можно ли продавать стикеры с Creeper из Minecraft на Redbubble?
```

Субагент читает `SYSTEM_PROMPT.md` и справочники из репозитория и использует WebSearch для проверки фактов.

## Ограничения

- Не юридическая консультация. Для 🟡 — консультация с US-attorney до запуска, для 🔴 — обязательно, если решаете действовать.
- Политики издателей, списки лицензионных программ, пошлины USPTO, пороги sales tax и тарифы меняются; агент проинструктирован проверять их на дату и указывать источник. Факты в справочниках — по состоянию на октябрь 2026.
- Агент не даёт советов по уклонению от обнаружения или обману платформ; «как обойти закон» он переводит в «какие легальные пути дают похожий результат».
